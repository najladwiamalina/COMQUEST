# COMQUEST

**ComQuest: Interactive Quiz Website for Computer Science Students**

ComQuest is an interactive quiz platform designed for Computer Science students at IPB University. It provides structured quizzes by subject and chapter, along with a reward system to make learning more engaging.

## Features

1. Interactive quizzes by subject and chapter
2. Quiz results and answer review
3. Points and reward system
4. Item shop and website customization
5. Leaderboard
6. User authentication and dashboard

## Tech Stack

HTML, CSS, JavaScript, Bootstrap, PHP, Laravel

## Methodology

Developed using **Agile Kanban** with an **Evolutionary Prototyping** approach.

**Backlog → Selected → Analysis → Development → Testing → Done**
